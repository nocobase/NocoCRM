NocoCRM — CRM с открытым исходным кодом для B2B-продаж, построенная на [NocoBase](https://www.nocobase.com). В неё встроены 6 агентов продаж, а ваша почта и WhatsApp подключаются к ней: агенты ведут лиды и сделки, сразу отвечают на сообщения и разбирают согласования вместе с вами. ## Возможности

- **Автоматическое сопровождение.** Новый лид или сделка, ответ клиента, выполненная задача, утренняя проверка: агент читает весь контекст и кладёт следующий шаг во входящие — с выводом, степенью уверенности и обоснованием. Записи меняются только после того, как вы примете предложение.
- **Все каналы на одной ленте.** Каждый подключает свой почтовый ящик (Gmail, Microsoft 365 или любой сервер IMAP/SMTP), компания — свой номер WhatsApp Business. Сообщения привязываются к лидам и контактам, а ответы готовятся для отправки с вашей собственной учётной записи.
- **6 агентов продаж.** Sales Expert, с которым можно говорить на любой странице, и ещё пять, работающих в фоне: сопровождение лида, сопровождение сделки, проверка согласования, подготовка задач и исследование компаний — у каждого свои триггеры, навыки и журнал запусков.
- **Умный ввод данных.** Вставьте письмо, переписку или визитку — ИИ сверит их с существующими записями и превратит в лиды или сделку, которые вы проверите перед сохранением. Для новой компании достаточно названия: ИИ дополнит её данные из интернета. Дубли лидов находятся и объединяются.
- **Сигналы о компаниях.** Каждое утро исследование компаний ищет в интернете новости о компаниях с открытыми сделками или из вашего списка наблюдения: финансирование, найм, смена руководства, шаги в бизнесе и риски — с источниками. Важный сигнал запускает сопровождение их открытых сделок.
- **Согласования больше не буксуют.** Агент согласований сверяет скидку или условие с вашими правилами и прошлыми решениями и готовит для согласующего рекомендацию и комментарий.
- **Весь цикл продаж.** Лиды, компании, контакты, сделки, задачи, согласования и отчёты, а также доска сделок, календарь задач и поиск по всем записям (⌘K / Ctrl+K); права по ролям сервер применяет к каждой записи.
- **Настраивается под вас.** Опишите цены, пределы скидок и ритм работы с клиентами простым текстом в бизнес-инструкциях — и каждый агент будет им следовать; метод работы каждого агента — это навык, который можно править. Исходный код открыт, так что остальное изменит агент для программирования.
- **Собственный хостинг.** Данные остаются на ваших серверах, модели — на ваш выбор: DeepSeek, OpenAI, Claude, Gemini, Qwen и другие.

## Быстрый старт

Хотите просто посмотреть? [Попробовать онлайн](https://solutions.nocobase.com/crm/): вы сразу входите под демо-учётной записью, а все данные вымышлены.

### 1. Установка

**С помощью агента для программирования.** Самый простой способ. Откройте Claude Code, Codex или Cursor в папке, где будет NocoCRM, и дайте ему такое задание:

```text
Установи NocoCRM из https://github.com/nocobase/NocoCRM и запусти его, следуя AGENTS.md и README репозитория.
```

**Вручную.** Нужны Node.js 24 или новее и pnpm 11 (`corepack enable`). По умолчанию данные хранятся в файле SQLite; PostgreSQL и MySQL тоже поддерживаются.

```bash
git clone https://github.com/nocobase/NocoCRM.git
cd NocoCRM
pnpm install
pnpm nocobase config init --dialect sqlite
pnpm dev
```

### 2. Вход

Откройте адрес `Local:`, который выводит `pnpm dev`, обычно `http://127.0.0.1:13000/main/`, и войдите как `nocobase` с паролем `admin123`.

### 3. Импорт демо-данных

Их предлагает баннер вверху страницы, или откройте **Настройки → Демо-данные**. Они добавляют отдел продаж с клиентами, сделками, задачами, согласованиями, почтой и переписками; удалите их там же, когда начнёте работать всерьёз.

### 4. Настройка модели ИИ

Добавьте сервис моделей с ключом в разделе **Команда Agent → Модели**, например DeepSeek, OpenAI, Claude, Gemini или Qwen. Он нужен ассистенту и агентам; всё остальное работает и без него.

В [руководстве](guide.md) (на английском) описаны дальнейшие шаги, демо-учётные записи, роли, настройка (ИИ, почта, WhatsApp, базы данных), развёртывание и разработка.

Развёртывание в продакшене описано в разделе [Deployment](guide.md#deployment), работа с PostgreSQL и MySQL — в разделе [Configuration](guide.md#configuration).
